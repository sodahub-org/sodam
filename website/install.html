安装 SodaM

当前版本 —。三个平台都提供预编译包；源码安装见 开发者文档。

Linux

支持 x86_64 与 aarch64（含 Arch Linux ARM）。包依赖 alsa-lib、dbus、fontconfig、freetype2、 libxkbcommon、libxcb，由 pacman 自动处理。

方式一：加 pacman 源（推荐，可随系统升级）

1. 编辑 /etc/pacman.conf，末尾追加
[sodam]
SigLevel = Optional TrustAll
Server = https://sodahub-org.github.io/sodam/$arch
2. 安装
sudo pacman -Sy sodam

之后 sudo pacman -Syu 会一起升级。仓库内容由 CI 在每次发版后重建， 地址：sodahub-org.github.io/sodam。 包未做 GPG 签名，所以用 Optional TrustAll；要严格校验请用方式二。

方式二：下载包手动安装

下载并校验
mkdir -p /tmp/sodam-install && cd /tmp/sodam-install

arch=$(uname -m)          # x86_64 或 aarch64
version=$(curl -fsSL https://api.github.com/repos/sodahub-org/sodam/releases/latest | grep -m1 tag_name | cut -d '"' -f4 | tr -d v)
base=https://github.com/sodahub-org/sodam/releases/download/v${version}

curl -fLO ${base}/SHA256SUMS
curl -fLO ${base}/sodam-${version}-1-${arch}.pkg.tar.zst
grep "sodam-${version}-1-${arch}\.pkg\.tar\.zst$" SHA256SUMS | sha256sum -c -
安装
sudo pacman -U ./sodam-*-1-${arch}.pkg.tar.zst

启动

命令行
sodam

也可以从应用菜单启动 SodaM。首次启动进入设置页，按提示扫码登录。

macOS（Apple Silicon）

需要 macOS Monterey (12) 或更高，仅支持 arm64。

方式一：Homebrew（推荐）

安装 / 升级
brew install --cask sodahub-org/tap/sodam
brew upgrade --cask sodam

方式二：下载 .app

从 Releases 下载 sodam-<version>-macos-aarch64.zip，解压后把 SodaM.app 拖进「应用程序」。

应用为 ad-hoc 签名，首次打开若被 Gatekeeper 拦截：右键点图标 →「打开」→ 再确认一次， 或在「系统设置 → 隐私与安全性」里选择「仍要打开」。

Windows（x64）

Windows 10/11 x64。安装包按用户安装，不需要管理员权限。

  1. 从 Releases 下载 sodam-<version>-windows-x64-setup.exe。
  2. 双击运行，按向导完成安装（默认目录 %LOCALAPPDATA%\Programs\SodaM）。
  3. 首次运行若弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（安装包未做代码签名）。

配置保存在 %APPDATA%\sodam\config.json，覆盖安装不会丢失。

校验下载

每个 Release 都带 SHA256SUMS。Linux/macOS：

sha256sum
sha256sum -c --ignore-missing SHA256SUMS

Windows PowerShell：

Get-FileHash
$expected = (Select-String -Path SHA256SUMS -Pattern "setup\.exe$").Line.Split(' ')[0]
$actual = (Get-FileHash .\sodam-*-setup.exe -Algorithm SHA256).Hash.ToLower()
if ($expected -eq $actual) { "SHA256 OK" } else { throw "SHA256 mismatch" }

卸载

平台操作
Arch Linuxsudo pacman -Rns sodam（从 pacman.conf 里删掉 [sodam] 段即为断开源）
macOSbrew uninstall --cask --zap sodam，或把 app 拖进废纸篓
Windows设置 → 应用 → SodaM → 卸载

配置与缓存目录：Linux ~/.config/sodam / ~/.cache/sodam， macOS ~/Library/Application Support/sodam，Windows %APPDATA%\sodam。 需要彻底清理时手动删除即可。

常见问题

没有声音 / 音频设备不可用

先确认系统里有可用的输出设备，然后在 设置 → 音频 里看错误提示。播放中切换默认输出设备（音响 ↔ 耳机） 会在 2 秒内自动跟随，不需要重启。

扫码登录后还是未登录

确认网络能访问汽水音乐接口；如果使用的是远程签名服务，检查设置里的签名地址与 Token。

Linux 下没有标题栏按钮

GNOME 等使用客户端装饰的桌面会由应用自绘最小化/最大化/关闭按钮；Hyprland/sway 这类平铺桌面 仍然由系统管理窗口（无标题栏），用桌面自己的快捷键即可。

能装到非 Arch 的 Linux 吗

目前只发布 pacman 包。其它发行版可以从源码构建（见 开发者文档）。
