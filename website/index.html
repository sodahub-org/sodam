SodaM 是 汽水音乐 的第三方客户端，用 GPUI + Rust 原生渲染 —— 高性能、低占用、高颜值。操作手感对齐官方客户端，同时把本地缓存、 无损播放和主题做到了更舒服的程度；Linux / macOS / Windows 都能用。

非官方项目：SodaM 由社区开发维护，与汽水音乐官方无关；账号与曲库仍来自汽水音乐官方服务。

界面

原生渲染、跟随系统主题，封面与歌词都是为桌面优化的布局。

特性

日常听歌真正用得上的那几件事。

高性能

GPUI 原生渲染，不是套壳网页

Rust + GPUI 直接调用系统窗口与 GPU：启动快、滚动和动画不掉帧，中英文输入法都是原生手感。

低占用

单进程，没有额外常驻

一个进程跑完界面与播放，关窗驻留托盘；没有 Electron 运行时、没有后台服务、没有遥测。

高颜值

干净的自适应主题

深色主题跟随系统外观，播放页按封面取色生成氛围背景，歌词与封面布局按桌面尺寸优化。

播放

无损音质与本地缓存

解密后的音频落本地缓存，可设上限自动淘汰；切歌不再等网络，弱网也稳。

跟随系统

切换输出设备自动跟随

播放中把默认输出从音响换成耳机，2 秒内切过去并从原位置续播，不用重启。

功能

推荐流 · 听歌模式 · 搜索

推荐流、场景电台、搜索、歌单、我喜欢的音乐、艺人/专辑页都能用，按官方接口取数。

集成

系统媒体键与桌面挂件

MPRIS（Linux）、macOS Now Playing、Windows SMTC 都已接入，键位和挂件直接可控。

下载

选择你的平台；完整的校验、卸载与疑难排查见 安装说明。

Windows（x64）

按用户安装的安装包，不需要管理员权限，自带开始菜单快捷方式。

安装方法 下载安装包

30 秒装好

Arch Linux（含 Arch Linux ARM）可以直接加源，之后随 pacman -Syu 升级。

/etc/pacman.conf 末尾
[sodam]
SigLevel = Optional TrustAll
Server = https://sodahub-org.github.io/sodam/$arch
安装
sudo pacman -Sy sodam
macOS · Homebrew
brew install --cask sodahub-org/tap/sodam
