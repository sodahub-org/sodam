# UI 规范（sodam）

目标是保持汽水官方客户端的整齐层级，同时利用 GPUI fork 获得顺滑滚动。
本文记录现行 UI 约束和性能边界，避免页面各自引入新规则。

## 1. 参考与原则

- 官方 PC 客户端：层级、密度、播放栏结构、播放页比例。
- sonora：虚拟列表、滚动手感、图片并发控制、主题分层思路。
- 所有尺寸从 `ui/theme.rs` 读取，不在页面里随意散落 magic number。

## 2. 主题与颜色

- 主题只有 `Dark` 和 `Light`；首次启动跟随系统，用户选择后持久化。
- 全局背景使用浅渐变；表面、边框、文本都基于同一 ambient hue 微调。
- 封面主色进入 `theme::set_ambient_rgb` 后影响背景、选中态、强调色和 logo。
- 不引入第二套固定强调色。按钮主色使用 `theme::accent()`，
  主色上的文字使用 `theme::accent_foreground()`。
- logo 有独立四色模板：主色、互补色、两个相近色。

## 3. 尺寸

当前基准：

- 侧边栏：216px
- 底部播放栏：76px
- 间距：4 / 8 / 12 / 16 / 24 / 32
- 圆角：6 / 8 / 12 / 999
- 图标：14 / 16 / 20 / 24
- 字号：`Tiny` / `Small` / `Body` / `Large` / `Title`

播放页参考汽水官方比例：

- 封面宽度：`min(40vh, 30vw)`
- 歌词列宽度：`30vw`，并限制在 `300px ~ 500px`
- 封面与歌词间距、页面水平边距：约 50px
- 窗口比官方最小尺寸更窄时，封面与歌词按比例整体收缩

## 4. 布局

### 侧边栏

- 品牌 logo + `SodaM`
- 固定入口：Discover、Listening Modes、Search、Settings
- My Music 分组：Liked Music、My Playlists
- 选中项用 accent；未选中项用 muted 文本。

### 播放页

- 左侧封面居中，封面下方是歌名、VIP、喜欢、歌手。
- 右侧歌词或队列占据固定宽度。
- 歌词列表当前行跟随播放进度；队列视图替换歌词区域。
- 封面 / 歌词加载失败时显示重试；原图未就绪时提示并允许重试。

### 列表

- 长曲目列表使用 `uniform_list` 虚拟化。
- 表头与行共享列宽计算；窄窗口自动减少列。
- 行内喜欢按钮阻止事件冒泡，不触发行播放。
- 正在播放的行高亮，与 hover 效果一致。
- 歌名点击打开专辑页，歌手点击打开音乐人页。

### 播放栏

- 左侧：封面、歌名、喜欢、歌手、音质标签。
- 中间：上一首、播放 / 暂停、下一首和进度。
- 右侧：音量与队列开关。
- 左侧歌手行不重复显示时间；时间由中间进度条负责。

## 5. 文案与 i18n

- 用户可见文案必须走 `root.tr` / `root.localized`。
- 中文原文作为 key，英文词典在 `ui/i18n.rs`。
- 命名占位符（如 `{err}`、`{added}`）会按顺序填充。
- 不把服务端中文数据当作 UI key；听歌模式名称通过 `scene_display_text` 映射。

## 6. 性能约束

1. 渲染路径禁止网络请求和阻塞 IO。
2. 长列表使用 `uniform_list` / `gpui::list`，只渲染可见项。
3. 封面请求池有并发上限、去重和队列上限。
4. 渲染只读取 `Arc` 缓存，不深拷贝大列表。
5. `SODAM_FRAME_LOG=1` 可观察超过 16ms 的帧；
   `SODAM_SCROLL_TEST=1` 可做滚动压测。

## 7. GPUI 版本

使用 `sodahub-org/gpui` fork，而不是 crates.io 的 `gpui 0.2.2`。
fork 包含 sonora 使用的滚动与平台改进。升级时修改 `Cargo.toml` 的 `rev`，
更新锁文件后运行 `scripts/check.sh`，并在真机检查滚动。
