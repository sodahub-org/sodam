# Roadmap

当前仓库已经从骨架阶段进入可用桌面客户端阶段。本文记录已完成能力与下一阶段工作。

## 已完成

- [x] GPUI 主窗口、侧边栏、内容路由、底部播放栏
- [x] Dark / Light / 系统主题；封面主色驱动的全局渐变和强调色
- [x] 配置文件与环境变量补全；音质偏好；语言与主题设置
- [x] 扫码登录、账号信息读取、退出登录
- [x] libresoda 接入：搜索、推荐、听歌模式、歌单、收藏、播放、歌词、元数据
- [x] rodio 播放线程、进度、音量、播放模式、自然播完切歌
- [x] 封面缓存、原图/缩略图分层、失败重试
- [x] 搜索综合 / 歌曲 / 音乐人 / 专辑 / 歌单
- [x] 歌手页、专辑页；歌曲名与歌手名跳转详情页
- [x] 我喜欢的音乐、我的歌单、收藏状态
- [x] 推荐队列、听歌模式队列、探索歌单
- [x] 播放页封面、逐字歌词、队列视图
- [x] 虚拟列表、图片并发池、帧耗时与滚动压测工具
- [x] 中英文界面、系统托盘、关闭到托盘
- [x] Arch Linux ARM64 打包与桌面入口

## 近期优先级

### 1. 稳定性

- [ ] 拉流失败、签名过期、网络中断的统一恢复体验
- [ ] 队列缓存与账号数据在重启后的可预测恢复
- [ ] 长时间播放的内存 / 文件缓存清理策略
- [ ] 更多离线测试覆盖 queue、搜索详情、设置迁移

### 2. 歌单管理 UI

- [ ] 创建歌单
- [ ] 修改歌单名 / 分类
- [ ] 添加 / 移除歌曲
- [ ] 歌单内排序
- [ ] 删除歌单确认与结果反馈

### 3. 搜索与详情增强

- [ ] 搜索联想词 UI
- [ ] 热搜词 UI
- [ ] 专辑 / 艺人分页加载完善
- [ ] 更多空态、错误态与重试一致性

### 4. 播放体验

- [ ] 播放模式 UI 完整化（当前队列内部状态已支持）
- [ ] 音质标签和签名状态的更清楚提示
- [ ] 歌词滚动微调与逐字动画一致性
- [ ] 队列拖拽排序

### 5. 平台与发布

- [ ] 配置文件版本迁移
- [ ] 干净机器安装测试
- [ ] x86_64 Linux 包验证
- [ ] macOS / Windows 支持评估
- [ ] 自动化 CI（带资源护栏）

### 6. 登录与账号

- [x] MFA / 二次验证流程闭环（2046：libresoda 官方组件桥接 + 自动拉起验证窗口；待真机 2046 场景验收）
- [ ] 登录失败原因分类展示
- [ ] Cookie 过期检测与重新登录引导

## 非目标

- 不做公共签名代理。
- 不做绕过会员权益的公共服务。
- 不分发官方客户端二进制或用户凭据。
